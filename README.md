# Identificaci-n-de-Genero-con-Redes-Neuronales
Aplicación de escritorio educativa para la detección de rostros y clasificación de género en tiempo real, utilizando Visión por Computadora (OpenCV/YuNet) y Deep Learning (TensorFlow, Keras y DeepFace). Incluye visualización de filtros, mapas de características y gamificación.
